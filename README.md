## Fase 4 - Componente Práctico - Prácticas Simuladas

### Manejo de excepciones en Python

**Objetivo**

Implementar el manejo de excepciones en una aplicación orientada a objetos, permitiendo controlar errores y mejorar la estabilidad del programa.

### Descripción del proyecto

Se desarrolló una calculadora en Python utilizando programación orientada a objetos, mediante una clase llamada `Calculadora`, que permite realizar divisiones y controlar posibles errores durante su ejecución.

### Excepciones implementadas

- `try`: intenta ejecutar el código.
- `except`: captura los errores.
- `else`: se ejecuta cuando no ocurren errores.
- `finally`: se ejecuta siempre.
- `raise`: genera una excepción cuando se intenta dividir entre cero.

### Pruebas realizadas

1. División con números válidos.
2. División entre cero.
3. Ingreso de datos incorrectos.

### Herramientas utilizadas

- Python.
- Visual Studio Code.
- GitHub.

### Conclusión

La actividad permitió comprender la importancia del manejo de excepciones en Python, aprendiendo a identificar y controlar errores para desarrollar aplicaciones más estables y confiables.
